1 Connect your iPhone Shortcut

The Save Reel to Map Shortcut sends a Reel and a screenshot of it from Instagram → Share. It uses a personal link from this page, so Reels go to your collection on this reelocations installation. You can revoke the link below at any time.

On this iPhone:

  1. Tap Create my Shortcut link, then Copy.
  2. Open the Save Reel to Map Shortcut and tap Add Shortcut. When it asks for your link, paste it.
  3. Already have the Shortcut? Open Shortcuts → long-press Save Reel to Map → Edit, and replace the old link with the new one (the URL used by Get Contents of URL).
  4. Test it: in Instagram, open a Reel → Share → Save Reel to Map.
Setting up a different iPhone? Use a one-time code instead

Create a code here and enter it on the other iPhone at reelocations → Sign in, or in a Shortcut that calls /api/pair. Codes work once and expire after 10 minutes.

2 Save places to a Google Maps list (optional, beta)

The server saves each place's real Google Maps listing (the right branch) to a list in your Google account, so it opens its normal place card in the Google Maps app — even when your computer is off. Google has no API for this, so the server uses your Google Maps session in a browser. Only Reels you share after you first connect are saved (places you saved before are left out), and only once their listing is verified; approximate or unclear ones wait in the Review Queue.

Tap Sign in to Google: Google's own sign-in page opens in the server's browser and is shown here, so you can do it on this iPhone. What you type goes over a secure connection to this server and into Google's page; it is not stored or logged. The server keeps only its browser's signed-in session. Signing in again keeps your list, what was saved, and what is waiting.

Other way: sign in on a computer

Tap Create Google Maps code, run the command shown on a computer with Chrome and this project, and sign in to Google in the window that opens. Only the browser session is sent to this server. Google may sign such a copied session out again after a few hours; signing in here on the server lasts.

3 Google My Maps per country (optional, desktop)

Google My Maps has no public API. Only a browser signed in to your Google account can add places to your maps, so a small program on your computer publishes them. Railway processes each Reel once; the computer only publishes finished pins, one map per country, for any number of countries.

  1. On your Windows computer with Chrome, open a terminal in the reelocations folder.
  2. Tap Create desktop code, then run the command shown below.
  3. The first time, a Chrome window asks you to sign in to Google. Do it yourself; reelocations never sees your password.
